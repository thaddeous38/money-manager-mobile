THADD MOBILE APP SOURCE# Money Manager Mobile

Starter Expo + TypeScript project for a mobile money manager app.

Quick start:

1. Install dependencies:
   npm install
2. Start Expo:
   npm run start

This initial scaffold includes:
- Basic navigation (Dashboard, Add Transaction)
- Local SQLite helper (expo-sqlite)
- Minimal TypeScript configuration

Next: install native dependencies for navigation if needed and run on a simulator or device using Expo Go.
